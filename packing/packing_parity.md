# Open-Jev-9B mixed packing parity

`packing_parity.rs` replays 18 deterministic token cases (94 candidate logits)
against an oracle generated by original native commit
`22b7717c9710de5ac5c6ccba51a6d6686dae90d9`. That revision runs 9B candidates
individually. The verification checkout packs them. This is an execution
regression test, not a task-accuracy or performance benchmark.

The fixture covers mixed lengths 128/257/511, permutations, changed tokens and
returning inputs, unaligned lengths, total lengths 4095/4096/4097, 16/17
candidates, multiple questions, and a long singleton-group control. Each case
declares the expected original packing groups; the CPU check calls the actual
production grouping function. The GPU check asserts that 9B packing is enabled,
prefix reuse is disabled, and the returned FP32 learned-head logits match the
frozen original **bit for bit**, before response normalization. It also checks
question/candidate counts. New-code singleton output is not the oracle.

The reference is scoped to the pinned BF16 9B export from
[the native recipe](https://github.com/InferMatrixLab/system1-omni/blob/ecea1a31e287890fee5a595504203b53734ffe2a/recipe/open_jev/native.md), NVIDIA L20X / measured
SM90, CUDA 13.0. Bitwise agreement on other architectures/toolchains is
unverified. Arbitrary synthetic token IDs do not establish semantic accuracy.
The existing typed HTTP benchmarks separately check Noul/Choice/Score outputs.

## Verify the committed reference

Build the current Rust worker and matching CUDA library as in the recipe. Set
`OPEN_JEV_MODEL` to the pinned export and `OPEN_JEV_CUDA_LIB` to the current
library. On the measured host, build the CUDA library with architecture `90`.

```bash
cargo test --locked -p omni-open-jev-native --test packing_parity

# Run the following inside your host's GPU reservation, e.g. gpu run -- ... .
for graph in 0 1; do
  OPEN_JEV_PREFIX=0 OPEN_JEV_EXACT_PREFIX=0 CUA_S1_GRAPH="$graph" \
    cargo test --release --locked -p omni-open-jev-native \
      --test packing_parity mixed_packing_matches_frozen_original_native \
      -- --ignored --exact --nocapture --test-threads=1
done
```

The explicit `record_original_native_reference` test is intentionally ignored
and refuses to run with packing enabled. Do not run all ignored tests in this
target: recording and verification require different source revisions.

## Independently regenerate the original oracle

Use a fresh worktree and **separate Cargo target directories**. Sharing a target
directory across these checkouts can reuse a test binary from the wrong source.
The packing-enabled assertion detects that mistake, but isolation prevents it.

From the PR checkout, with absolute `REPLAY_DIR` and `OPEN_JEV_MODEL` paths:

```bash
PR_CHECKOUT="$PWD"
ORIGINAL=22b7717c9710de5ac5c6ccba51a6d6686dae90d9
mkdir -p "$REPLAY_DIR"
git worktree add --detach "$REPLAY_DIR/original" "$ORIGINAL"
cp tests/open_jev/packing_parity.rs "$REPLAY_DIR/original/tests/open_jev/"
cp tests/open_jev/data/packing_{cases,original}.json \
  "$REPLAY_DIR/original/tests/open_jev/data/"
cat >> "$REPLAY_DIR/original/src/models/open_jev/native/Cargo.toml" <<'EOF'

[[test]]
name = "packing_parity"
path = "../../../../tests/open_jev/packing_parity.rs"
EOF

cd "$REPLAY_DIR/original"
test "$(git rev-parse HEAD)" = "$ORIGINAL"
# Configure NVCC/CPATH/LIBRARY_PATH for your CUDA installation as needed.
src/backends/cuda/qwen3_5/build.sh "$REPLAY_DIR/cuda-original" 90
CARGO_TARGET_DIR="$REPLAY_DIR/target-original" \
  cargo test --release --locked -p omni-open-jev-native \
    --test packing_parity --no-run

# Inside a GPU reservation; original production source is unchanged.
OPEN_JEV_CUDA_LIB="$REPLAY_DIR/cuda-original/libqwen3_5_cuda.so" \
OPEN_JEV_ORACLE_OUTPUT="$REPLAY_DIR/original-reference.json" \
OPEN_JEV_PREFIX=0 OPEN_JEV_EXACT_PREFIX=0 CUA_S1_GRAPH=0 \
CARGO_TARGET_DIR="$REPLAY_DIR/target-original" \
  cargo test --release --locked -p omni-open-jev-native \
    --test packing_parity record_original_native_reference \
    -- --ignored --exact --nocapture --test-threads=1

cmp "$REPLAY_DIR/original-reference.json" \
  "$PR_CHECKOUT/tests/open_jev/data/packing_original.json"
cd "$PR_CHECKOUT"
```

Then run verification above with the PR's CUDA library and a distinct candidate
target directory. Keep stdout/stderr, source revisions, library/executable
SHA256 hashes, GPU identity, export-file hashes, and both successful and failed
attempts. A regenerated oracle mismatch is a failed check; do not overwrite the
committed oracle to make verification pass.
